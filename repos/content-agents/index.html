content-agents

NVIDIA 的 AI 驱动 3D 内容自动化框架 · VLM 看图分析 USD 资产 · v0.4.3

这个仓库做什么

用 VLM（Vision-Language Model）分析 USD 资产的多视角渲染图，自动分配材质、分类物理属性、生成纹理、校验生成内容。4 个 agent（Material / Physics / Texture / Validation）各有 CLI + REST 服务两种形态。本质上是 "3D 渲染 → VLM 看 → 推理 → 改 USD" 的 agentic pipeline。

所有 agent 标 Beta 或 Research Preview。仅支持 Linux/WSL2 —— 无原生 Windows/macOS。

横向：.agents/skills/ 25 skills → agent 的"使用说明书"（给 coding agent 读的）

关键设计约定

  • Tool = func + ToolSpec：装饰器注册，import 即生效
  • VLM 通过 LangChain function-calling 调 tool：人不能直接调 tool
  • YAML DSL 描述 pipeline：config 结构在 4 个 agent 间复用
  • Render → Predict → Apply → Validate：标准闭环
  • Data URI by default：渲染图 base64 inline（免 S3）
  • OpenTelemetry 全链路：每个 tool invocation 自动 span

§练习 · 实战检查点（Practice Tasks）

练习 1 · 预判资产会被怎么处理

模块：心智模型　难度：★☆☆　预计：30 min

挑公开 USD（如 USDA Kitchen Set），预判：Material Agent 给哪些零件分什么材质？Physics Agent 分什么物理类型？Texture Agent 哪些面是纯色需纹理？Validation Agent 做什么校验？写一页预判表。后续实跑后回看预判 vs 实际。

练习 2 · install_all_cli.sh

模块：双模式架构　难度：★★☆　预计：1h

写 install_all_cli.sh：从零（无 repo）到 4 agent CLI 都能 --help。clone→uv venv→install core+4 agents→fetch build→验证。至少跑 material-agent --help。

练习 3 · 加一个自定义 tool

模块：核心库　难度：★★☆　预计：1h

在 tools/cv/ 下新建 fake_tool.py，写 DescribeColorTool：input_model ColorInput(color:str)→output_model ColorOutput(description:str)，@register_tool 注册。在 tools/__init__.py 和 tools/cv/__init__.py 加 import。验证 register_all_tools() 返回你的 tool。

练习 4 · inspect_tools.py + call_tool.py

模块：Tool Registry　难度：★★☆　预计：1h

写 inspect_tools.py（import register_all_tools，打印所有 tool 的 name/input/output/tag）。再写 call_tool.py 对 get_dominant_colors_tool 构造合法 input 调 Tool.run()，验证 output。

练习 5 · 修改 unified_example for your asset

模块：Material Agent　难度：★★★　预计：1.5h + GPU

复制 unified_example.yaml 为 my_asset.yaml，改 3 处：(1) usd_path 指向你的 USD；(2) backend 根据你的 API key 改；(3) 禁用 optimize/apply，只跑到 predict。看 VLM 给你的资产选了哪些材质。无环境至少用 yaml.safe_load 验证结构。

练习 6 · 手动 Physics Agent

模块：Physics Agent　难度：★☆☆　预计：20 min

对桌上任意物体拍 3 张照片，你替代 VLM 做 Physics prediction：material type / component function / mass/density/friction/deformability / asset type。写 structured 结果。

练习 7 · 扫描 empty texture slots

模块：Texture Agent　难度：★★☆　预计：45 min

对已有 material binding 的 USD，用 pxr.UsdShade 遍历 prim，统计"有 material binding 但无 texture file path"的数量。无 USD 就理解 discover 命令的作用。

练习 8 · Human validator

模块：Validation Agent　难度：★☆☆　预计：20 min

挑任意 3D 渲染图，做 look right judge：你看到什么？预期什么？verdict pass/fail？1 句理由。思考：VLM 能做这判断吗？什么情况 VLM 会误判？

练习 9 · 写一个最小 agent skill

模块：Agent Skills　难度：★★☆　预计：1h

仿 material-agent-cli SKILL.md 格式，写 my-first-skill SKILL.md（30-50 行）：frontmatter / When to Use / First Command。放 .agents/skills/ 下。分析：如果 Claude Code 加载这个 skill，什么用户请求会激活它？与 CLAUDE.md 按场景调度有何异同？

练习 10 · 修改渲染配置

模块：Render　难度：★★☆　预计：45 min

用 yaml.safe_load 读 unified_example.yaml 的 renderer，改 3 项：(1) backend remote→local；(2) resolution 512→1024；(3) 加 "+x-y+z" 视角。解释每项如何影响 VLM 预测质量。有 GPU 就跑一遍实测差异。
